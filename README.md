# Proyecto M

Prueba de desarrollo coordinado por agentes.

Tablero: [Tablero con Mario](https://trello.com/b/6ssUenDd/tablero-con-mario).

Cada ticket se vincula con una issue, una rama y un pull request. El PM revisa el tablero cada hora y delega la implementación a un agente GPT-6 Sol con razonamiento medio por ticket.

Flujo: To Do → Work In Progress → Review → Done. Done requiere criterios de aceptación verificados y cambios integrados.

El alcance y la tecnología se definirán a partir de los tickets del tablero.
